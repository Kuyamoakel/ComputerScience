this simple program is not only inheritance practice, but with the 4 pillars of OOP.

### Abstraction – Pet is an abstract class with abstract methods like play() and sound().

### Inheritance – Dogs and Cats extend Pet, and specific breeds (Pitbull, Golden Retriever, Himalayan, Persian) inherit from them.

### Encapsulation – Pet details (name, breed, age) are private, with getters and a setter for controlled access.

### Polymorphism – Each pet overrides play() and sound() differently, so the same method call behaves uniquely at runtime.
